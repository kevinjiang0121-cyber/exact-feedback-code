# Experimental validation

Thirty-two offline analysis jobs completed successfully on the separate anonymous evidence tree. Twenty model-execution entries produce 294 command steps; 85 model/experiment plans were preserved during migration to 17 implementation classes. These are execution-plan checks, not model-generation tests.

Recomputed frozen results include response discovery/confirmation and natural-trajectory prediction, robustness, recurrence and capture, API interactions, history interventions, crossover, Llama restoration/dose/activation/grafts, and Qwen/Gemma mechanism analyses. The partial-history analysis reconstructs 240 arms from 120 new tail-window arms and 120 reused full/reset arms; all 574 shared numeric fields match the frozen report. All nine cross-family history cells reproduce their published rates and terminal intervals. Frozen bootstrap/permutation counts are retained per analysis.

All 27,359 common failure labels match the frozen classification. Round-budget analysis matches 513 cell rows and nine summaries. Annotation integrity is checked against the frozen Stanza/NLI records. The separate evidence release records the completed jobs; `experiment_index.json` maps 22 experimental evidence groups to files and commands.

## Numerical limits

Passing a job means that its analysis and integrity checks completed; it does not imply that every floating-point output is bitwise identical. Windows and Linux continuous ridge-probe results differ even with NumPy 2.2.6, SciPy 1.15.3 and scikit-learn 1.7.2 pinned. Reported final-layer classification estimates match. An auxiliary Gemma target probe can select a different regularization value; the estimator is preserved rather than forced to reproduce stored fitted values. Reanalysis on the original Linux host matched both Qwen/Gemma frozen probe reports on all common fields.

Three-domain fitted regression statistics also show small platform-level numerical differences; trajectory counts and labels remain unchanged. Path separators and provenance field names can differ across releases. The frozen source reports remain in the evidence package for direct inspection.

## Execution scope

No new model generation, GPU experiment or paid API call was run during packaging. Generation commands were checked structurally, and statistical analyses were executed on existing frozen measurements. A complete fresh inference run remains untested in this preparation. Historical API snapshots may no longer be available; new generations need not be byte-identical. Local generation requires the specified weights and a compatible Linux/CUDA environment. No manuscript, plotting or typesetting reproduction is included.

Full annotation model downloads and model inference were not executed in this preparation.
